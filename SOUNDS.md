# Built-in alarm sounds

All seven tones in `MyApp/Sounds/` are **original, synthesized audio** generated by
`tools/generate_sounds.py` (sine / square / FM-style waveforms written with numpy and converted to
CAF with `afconvert`). They contain no third-party samples, so there are no licensing restrictions.
Regenerate them with `python3 tools/generate_sounds.py`.

| File | Description | Length |
| --- | --- | --- |
| Radar.caf | Repeating two-pulse beep with a higher tail | 12.8 s |
| Chimes.caf | Bell arpeggio, three passes | 21.6 s |
| Beacon.caf | Alternating 660 / 880 Hz pulses | 12.0 s |
| Digital.caf | Four-beep square-wave bursts | 10.4 s |
| GentleRise.caf | Soft chord that swells over time | 20.0 s |
| Rooster.caf | Pitch-gliding "cock-a-doodle" calls | 15.2 s |
| Siren.caf | Rising / falling sweep | 16.0 s |

Every file is under 30 s, the limit iOS places on alarm / notification sounds. Apps cannot use
Apple's own system ringtones, which is why these are bundled instead.
